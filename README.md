# Podcast Clipping Skill

Hermes skill for turning long-form podcast footage into retention-focused short clips.

## Install

Copy this directory to `~/.hermes/skills/media/podcast-clipping/`.

- `skills/motion-typography/` — preset motion typography, text supers, visual modules, and animation QA.
- `skills/words-behind-person/` — depth-aware hook text behind tracked subjects.
- `skills/zoom-shake/` — purposeful zoom, shake, tracking, and transitions.
- `skills/glass-interface-video/` — restrained glass overlays with protected zones.
